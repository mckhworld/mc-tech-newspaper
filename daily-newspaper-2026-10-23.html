Single-tenant Titus: VM-level isolation on a multi-tenant container platform

https://netflixtechblog.com/single-tenant-titus-vm-level-isolation-on-a-multi-tenant-container-platform-6d8b1909d163📅 2026-10-23 06:19 UTC+8

Netflix's internal container platform Titus runs millions of containers on shared hosts, but hardware-level interference from noisy neighbors—such as last-level cache contention, memory bandwidth saturation, and network softirq starvation—cannot be fully contained by kernel-level isolation mechanisms like cgroups. For demanding real-time streaming workloads, this interference causes stop-the-world events that page on-call engineers, so Netflix built single-tenant Titus, which gives a task its own dedicated virtual machine while preserving the platform's API, deployment path, and managed experience. The team evaluated microVMs, gVisor, and further shared-kernel tuning before concluding that a dedicated VM inside Titus best balances isolation guarantees with fleet efficiency and operational simplicity.

Netflix 內部嘅容器平台 Titus 將數百萬個容器放喺共享主機上運行，但係硬件層面嘅干擾——例如 last-level cache 爭用、記憶體頻寬飽和同網絡 softirq 飢餓——係 cgroups 等核心隔離機制無法完全解決嘅。對於要求極高嘅即時串流工作負載，呢種干擾會造成 stop-the-world 事件，逼到 on-call 工程師即刻起身處理，所以 Netflix 推出咗 single-tenant Titus，畀每個任務一個專屬虛擬機，同時保留平台原有嘅 API、部署流程同托管體驗。團隊評估過 microVM、gVisor 同進一步調校共享核心隔離，最終認為喺 Titus 入面用專屬 VM 係隔離保證、機群效率同運維成本之間嘅最佳平衡。
